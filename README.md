# Workplace AI

Welcome to **Workplace AI**! You can check out the live website here: [https://ai-workplace-product-3r2g.bolt.host](https://ai-workplace-product-3r2g.bolt.host)

## What is this?
Workplace AI is an all-in-one, AI-powered productivity platform designed to streamline your daily workflow. Built for modern teams and busy professionals, it automates repetitive administrative tasks, organizes complex projects, and helps you extract insights from your data instantly.

Think of it as an intelligent co-pilot built directly into your web browser to eliminate everyday busywork.

## Key Features
*   **AI Workspace Assistant:** Chat directly with an intelligent assistant to draft emails, generate code, brainstorm project plans, and refine content.
*   **Smart Document & Meeting Summarizer:** Instantly condense lengthy documents, meeting transcripts, and long email chains into key action items.
*   **Automated Task Generation:** Convert raw meeting notes or quick prompts into structured to-do lists with priorities and assigned deadlines.
*   **Interactive Workspace Dashboard:** Track ongoing tasks, monitor productivity metrics, and manage your daily priorities from a unified hub.

## Who is this for?
*   **Project Managers:** Keep deliverables organized and extract clear action items from team meetings.
*   **Freelancers & Consultants:** Manage multiple clients, automate email drafts, and speed up project planning.
*   **Remote Teams:** Centralize project communications and reduce time spent on administrative overhead.

## How it works
1.  **Launch the App:** Visit the live URL or run the application locally in your browser.
2.  **Select a Tool:** Choose between the AI Assistant, Document Summarizer, or Task Builder.
3.  **Input & Generate:** Enter your raw text or prompt to receive instant, formatted results that you can copy, save, or export to your workflow.

## Tech Stack
*   **Frontend:** React, TypeScript, Vite, Tailwind CSS
*   **Icons & UI Components:** Lucide React
*   **AI Integration:** OpenAI API / Anthropic SDK
*   **Deployment Platform:** Bolt.host
